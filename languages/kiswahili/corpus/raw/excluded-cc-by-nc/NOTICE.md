# CC-BY-NC Excluded Content - Provenance Only

The 15 files in this directory are African Storybook Project stories
that are individually licensed **CC-BY-NC (non-commercial)**, unlike
the CC-BY files in the parent `raw/` directory.

Per `docs/Enhancements.md` (M2.13), these files were deliberately
EXCLUDED from the production `kiswahili-storybook-text-v1` dataset
and are preserved here only for provenance and traceability - not
deleted, but also not usable for the same purposes as the CC-BY
content alongside them.

**Do not use these files for any commercial purpose.** Check each
file's own embedded `* License:` line, and the corresponding entry in
`frameworks/corpus-registry/registry/sources.json`, before any use.

explanation.
